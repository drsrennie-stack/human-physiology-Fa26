WHY THE FIRST AUDIT SAID CLEAN AND YOUR PAGES STILL DID NOT WORK
=======================================================================
The first pass checked whether a linked file exists. That catches a 404 and
nothing else, and none of what you were actually hitting was a 404:

  - A button with href="#" resolves fine. It just goes nowhere.
  - A PDF link inside a Canvas frame resolves fine. Canvas strips the
    permission to open a new tab, so the file loads inside the frame.
  - A script that fails to load leaves a page blank without erroring.
  - A page whose term start date is wrong shows the wrong week's content.

So this round I rendered all 302 pages in a real browser and recorded what
actually happened on load, and then tested the Canvas frame with the same
sandbox Canvas uses. That is where the real faults were.
